## LinkedIn

I passed the Microsoft Fabric Data Engineer Associate certification (DP-700), and I’m continuing to build on that milestone through hands-on practice.

Recently, I’ve been strengthening my SQL foundations with PostgreSQL using a small synthetic FinTech transactions dataset. I’ve practised joins, aggregations, CASE expressions, CTEs, and window functions such as ROW_NUMBER and LAG.

One useful lesson: ranking customers by completed transaction value is not just about writing a query. I need to define which transactions count, aggregate at the right level, handle ties consistently, and validate the result before using it to support decisions.

My next steps are to document the data requirements, build Python-based ingestion and data-quality checks, and then implement the workflow in Microsoft Fabric with monitoring and failure handling.

The certification is a milestone. The goal now is to demonstrate the skills through a working, documented project.
